# Changelog

Notable changes to this documentation repository, newest first. This file tracks the docs and examples in this repository only. Firmware and dashboard releases are not listed here.

## 2026-11-23

### Added

- Initial release of the SP100 usage documentation.
- README covering specifications, BTHome v2 advertisement, the Web Bluetooth dashboard and Home Assistant setup.
- `docs/calibration.md`, `docs/troubleshooting.md` and `docs/webble-gatt.md`.
- Three Home Assistant automation examples under `examples/home-assistant/`.
- `CONTRIBUTING.md` and issue templates under `.github/ISSUE_TEMPLATE/`.
- Support address and MIT license.

### Changed

- Aligned browser guidance with the user manual: Safari with Beacio first on iOS, Bluefy for older devices, Chrome on desktop.
- Aligned the low battery example with the sensor: 20% is an adjustable example threshold, not a device-defined low battery level.
- Removed values and wording without a source in the current manual: metric conversions, the submerge warning in the specification table, the moisture specification row and Bluetooth proxy mentions.
